# Read in Context UI

## Новый UI для чтения книги создан!

Теперь вы можете читать книгу в контексте секций по абзацу.

## Путь к странице

```
/read-in-context/[id]
```

Где `[id]` - это ID абзаца.

## Компоненты

### 1. **page.tsx** - Главная страница
- Загружает данные через API `/api/paragraphs/[id]/context`
- Отображает главу, секцию и все абзацы секции
- Автоматически скроллит к целевому абзацу
- Показывает навигацию вверху и внизу

### 2. **Paragraph.tsx** - Компонент абзаца
- Отображает содержимое абзаца
- Рендерит таблицы, иллюстрации и формулы
- Подсвечивает целевой абзац (желтым фоном)
- Показывает ID абзаца для отладки

### 3. **Navigation.tsx** - Компонент навигации
- Кнопки для перехода к предыдущей/следующей секции
- Использует ID первого абзаца для навигации
- Показывает название и номер секции

## Обновления API

API эндпоинт `/api/paragraphs/[id]/context` теперь возвращает:

```typescript
{
  chapter: { id, title, order },
  section: { id, title, number, order },
  paragraphs: [...],
  metadata: {
    previousChapter: {...} | null,
    nextChapter: {...} | null,
    previousSection: {
      id, title, number, order,
      firstParagraphId  // ID первого абзаца секции для навигации
    } | null,
    nextSection: {
      id, title, number, order,
      firstParagraphId  // ID первого абзаца секции для навигации
    } | null
  }
}
```

## Пример использования

1. Найдите ID любого абзаца в базе данных
2. Откройте в браузере: `http://localhost:3000/read-in-context/[paragraph-id]`
3. Страница загрузит всю секцию и автоматически прокрутит к выбранному абзацу

## Тестовый пример

Используя ID из вашей базы:
```
http://localhost:3000/read-in-context/chapter_глава-i-система-новейших-фундаментальных-открытий_1-гиперчастотная-механика-или-механика-микромира_p0
```
