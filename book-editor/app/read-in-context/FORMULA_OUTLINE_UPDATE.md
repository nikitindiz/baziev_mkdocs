# Formula Highlighting Update

## Изменения

### 1. Обновлена утилита рендеринга
**File**: `/lib/latex-renderer.ts`

Теперь ВСЕ inline формулы в тексте получают обводку:
- **Символы с high confidence** → зеленая обводка + tooltip
- **Остальные формулы** → серая обводка

### 2. Добавлены CSS стили
**File**: `/app/globals.css`

Новый класс `.regular-formula`:
```css
.regular-formula {
  border: 1px solid #9ca3af; /* серая обводка */
  padding: 2px 4px;
  border-radius: 4px;
}

.regular-formula:hover {
  background-color: #f3f4f6; /* светло-серый фон */
  border-color: #6b7280; /* темнее серая обводка */
}
```

## Визуальные эффекты

### Символы (high confidence)
- ✅ Зеленая обводка 2px
- ✅ Cursor: help
- ✅ Hover: светло-зеленый фон
- ✅ Tooltip с определением

### Обычные формулы
- ✅ Серая обводка 1px
- ✅ Hover: светло-серый фон
- ✅ Hover: более темная серая обводка
- ❌ Нет tooltip

### До и после

**До:**
```html
механически E = mv²/2 и k
         ↑ без обводки  ↑ зеленая обводка
```

**После:**
```html
механически E = mv²/2 и k
         ↑ серая обводка  ↑ зеленая обводка
```

## Темная тема

В темной теме:
- **Символы**: те же цвета
- **Обычные формулы**:
  - Обводка: `#6b7280` (gray-500)
  - Hover фон: `#374151` (gray-700)
  - Hover обводка: `#9ca3af` (gray-400)

## Regex для формул

Обновлен regex для поддержки номеров в скобках:
```javascript
/\{\{formula:([a-f0-9]+)(?::\([^)]+\))?\}\}/g
```

Теперь поддерживает оба формата:
- `{{formula:abc123def456}}`
- `{{formula:abc123def456:(12.11)}}`
