# Отчет о связывании параграфов с подразделами

## Проблема

1. **Исходная проблема**: Параграф `4:ada0754e-bb1f-4a0f-9369-70ac494ff593:9676` был связан с несколькими подразделами одновременно (дубликаты).

2. **Корневая причина**: Ошибка в логике `import_subsections.py` - метод `_reassign_paragraphs_to_subsection()` связывал параграфы с ВСЕМИ подразделами с порядком >= order параграфа.

3. **Неудачные попытки исправления**:
   - `fix_subsection_paragraph_links.py` - удалил ВСЕ связи (1572), не создав новые
   - `link_paragraphs_to_subsections.py` - создал 6630 связей, но многие оказались неправильными
   - `fix_subsection_paragraphs_correct.py` - не смог правильно подсчитать параграфы в markdown

## Решение

Создан скрипт `final_subsection_paragraph_linker.py`, который:

1. **Анализирует markdown файлы** для определения границ подразделов
2. **Парсит структуру**: находит заголовки `### N.` и считает параграфы между ними
3. **Создает точные связи** на основе order параграфов из базы данных
