# Унификация символов v → ν в §6 (ВЫПОЛНЕНО)

**Дата:** 26 декабря 2025  
**Статус:** ✅ Исправления внесены в базу данных

## Проблема

В §6 "Начала термодинамики в новом свете" для обозначения частоты структурных элементов активной стенки использовались два визуально похожих символа:

-   `v` (латинская буква v) - в параграфах p54-p66
-   `\nu` (греческая буква nu) - начиная с p70

Анализ показал, что это **один и тот же физический параметр**, набранный ошибочно из-за визуального сходства.

## Доказательства единства

### 1. Математическая идентичность формул

| Формула            | С v                  | С ν                  |
| ------------------ | -------------------- | -------------------- |
| Связь частот       | `f_1 = √(f_0 · v_1)` | `f_2 = √(f_1 · ν_2)` |
| Условие равновесия | `f_max - v_max = 0`  | `ν_max - f_max = 0`  |

### 2. Семантическая эквивалентность

-   `v_1`: "Частота структурных элементов активной стенки в состоянии 1"
-   `ν_i`: "частота структурных элементов стенки" (из текста p70)
-   `v_max`: "Максимальная частота структурных элементов активной стенки"
-   `ν_max`: "максимальная частота" стенки

### 3. Схема эволюции системы (p73)

```
f_0 → f_i → ν_i → ν_max
```

Символ `v` отсутствует в схеме, используется только `ν`.

## Важно: НЕ затронут другой символ v_1

**Symbol ID: 1766754265633**

-   `latex`: `v_1`
-   Описание: "Линейная скорость осциллятора в состоянии 1"
-   Единицы: м·с⁻¹
-   Используется в формуле p60: `v_1 = 2 A_1 · f_1`

Этот символ обозначает **скорость** (velocity), а не частоту, поэтому он **правильно** использует латинскую букву `v` и **не требует изменений**.

## Обоснование выбора ν (ню)

В физике принято:

-   `f` - frequency (частота)
-   `ν` (греческая ню) - frequency (частота, особенно в оптике и квантовой механике)
-   `v` (латинская) - velocity (скорость)

Базиев использовал `ν` для **отличия частоты стенки** от частоты газа `f`, что соответствует физической традиции.

## Проверка результата

```cypher
// Все символы с latex содержащим ν или v
MATCH (s:Symbol)
WHERE s.latex CONTAINS 'v_' OR s.latex CONTAINS '\\nu'
RETURN s.id, s.latex, s.description, s.units
ORDER BY s.latex
```

**Результат:**

-   `\nu_1` (1766677814323) - частота стенки, с⁻¹ ✅
-   `\nu_{max}` (1766676848817) - макс. частота стенки, с⁻¹ ✅
-   `v_1` (1766754265633) - скорость осциллятора, м·с⁻¹ ✅

**Конфликтов нет, все символы корректны.**
