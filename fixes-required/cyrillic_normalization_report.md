# Отчёт о нормализации кириллицы в формулах

**Дата**: 27 ноября 2025  
**Скрипт**: `graph-project/normalize_cyrillic_in_formulas.py`

## Задача

Заменить все прямые вхождения кириллицы в LaTeX-формулах на корректное оформление через `\text{}`.

## Статистика

-   **Всего формул с кириллицей**: 3374
-   **Исправлено формул**: 2111 (62.5%)
-   **Уже были корректны**: 1259 (37.5%)
-   **Осталось необработанных**: 4 (используют `\textrm{}`)

## Типы исправлений

### 1. Индексы

```latex
БЫЛО: \nu_{ед}
СТАЛО: \nu_{\text{ед}}

БЫЛО: m_э
СТАЛО: m_\text{э}

БЫЛО: n_к
СТАЛО: n_\text{к}
```

### 2. Степени

```latex
БЫЛО: n^ж
СТАЛО: n^\text{ж}

БЫЛО: k_0^ж
СТАЛО: k_0^\text{ж}
```

### 3. Единицы измерения

```latex
БЫЛО: 6292,2815 \ Дж
СТАЛО: 6292,2815 \ \text{Дж}

БУЛО: 10^{-19} Кл
СТАЛО: 10^{-19} \text{Кл}

БЫЛО: 272,76963 \ K < T_0
СТАЛО: 272,76963 \ \text{K} < T_0

БЫЛО: м/с
СТАЛО: \text{м}/\text{с}
```

### 4. Отдельно стоящие символы

```latex
БЫЛО: э
СТАЛО: \text{э}

БЫЛО: Б
СТАЛО: \text{Б}
```

## Необработанные случаи

4 формулы используют `\textrm{}` для кириллицы, что технически корректно:

| ID           | Формула        | Примечание |
| ------------ | -------------- | ---------- |
| 019110369c06 | `\textrm{ Тл}` | Тесла      |
| 4cde542cc3b6 | `\textrm{кг}`  | килограмм  |
| bcb8fc2f5747 | `\textrm{ Па}` | Паскаль    |
| e6df0fd45bcf | `\textrm{ м}`  | метр       |

`\textrm{}` и `\text{}` оба выводят текст прямым шрифтом, поэтому эти формулы можно оставить как есть.

## Алгоритм нормализации

Скрипт выполняет следующие шаги:

1. **Обработка индексов и степеней**: `_{...}` и `^{...}`
    - Если внутри есть кириллица и нет `\text{}`, оборачивает в `\text{}`
2. **Защита уже обработанных зон**:
    - Находит все блоки `\text{...}` и `\textrm{...}`
    - Помечает их как защищённые от дальнейшей обработки
3. **Обработка отдельной кириллицы**:
    - Находит все кириллические последовательности
    - Пропускает те, что в защищённых зонах
    - Оборачивает остальные в `\text{}`
