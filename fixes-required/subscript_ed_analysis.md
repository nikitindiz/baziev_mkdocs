### Варианты написания индекса "ед"

#### 1. `\text{ед}` (с командой \text)

Это основной и правильный вариант для обозначения текстовых индексов в LaTeX.

Примеры:

-   `\nu_{\text{ед}}` - частота единичная
-   `\tau_{\text{ед}}` - время единичное
-   `V_{\text{ед}}` - объем единичный
-   `m_{\text{ед}}` - масса единичная
-   `\varepsilon_{\text{ед}}` - энергия единичная
-   `E_{\text{ед}}` - энергия единичная
-   `l_{\text{ед}}` - длина единичная
-   `r_{\text{ед}}` - радиус единичный
-   `\omega_{\text{ед}}` - угловая частота единичная
-   `S_{\text{ед}}` - площадь единичная
-   `I_{\text{ед}}` - импульс единичный

**Количество: ~220 формул**

#### 2. `{ед}` (без \text, с кириллицей)

Встречается в формулах, где индекс набран кириллицей напрямую, без LaTeX-команды `\text`.

Примеры:

-   `\nu_{ед}`
-   `\tau_{ед}`
-   `m_{ед}`
-   `V_{ед}`

**Количество: ~48 формул**

### Комбинации индекса "ед" с другими индексами

#### Одиночные индексы (самый частый случай)

-   `\nu_{\text{ед}}` - только индекс "ед"
-   `\tau_{\text{ед}}` - только индекс "ед"

#### Комбинированные индексы

В базе НЕ обнаружено комбинаций индекса "ед" с другими индексами типа:

-   `_{i,\text{ед}}` - НЕ встречается
-   `_{\text{ед},i}` - НЕ встречается
-   `_{0\text{ед}}` - НЕ встречается

**Вывод:** Индекс "ед" всегда используется самостоятельно, без комбинации с другими индексами.

## Рекомендации

### 1. Нормализация написания

**Проблема:** В базе присутствуют два варианта написания:

-   `\text{ед}` (правильный LaTeX)
-   `ед` (кириллица без команды `\text`)

**Рекомендация:** Привести все к единому стандарту `\text{ед}` для корректного отображения в LaTeX/KaTeX.

### 2. Создание узла Symbol для "ед"

Рекомендуется создать в графе специальный узел Symbol для обозначения "ед" (единичный), который будет связан со всеми формулами, использующими этот индекс.

**Свойства узла:**

-   `symbol`: "ед"
-   `type`: "subscript"
-   `meaning`: "единичный" или "единица измерения"
-   `latex_variants`: ["_{\\text{ед}}", "_{ед}"]

### 3. Связи с единицами измерения

Индекс "ед" часто используется для обозначения единичных величин в системе единиц автора. Рекомендуется:

-   Связать формулы с индексом "ед" с соответствующими узлами единиц измерения
