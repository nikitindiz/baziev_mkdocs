# Анализ подстрочных индексов без кириллицы в формулах

Дата: 27 ноября 2025

## Контекст

Проанализированы все подстрочные индексы в формулах, которые не содержат кириллических символов. Данные извлечены напрямую из базы данных Neo4j.

## Наблюдения

1. **Форматирование пробелов неоднородно**: встречаются варианты `0i`, `0 i`, `0, i` для схожих индексов
2. **Астрономические символы используются активно**: есть множество вариантов записи планет и небесных тел
3. **Специальные математические обозначения**: `\min`, `\max`, `\text{rot}` используются в разных форматах
4. **Химические элементы**: активно используются в подстрочных индексах, часто с числами
5. **Греческие буквы**: особенно популярна лямбда с множеством комбинаций
6. **Ошибки и артефакты**: есть странные записи типа `???}`, пробелы, незакрытые фигурные скобки

## Рекомендации для дальнейшей нормализации

1. **Унифицировать пробелы**: решить, использовать ли `0i` или `0 i`
2. **Проверить незакрытые скобки**: индексы начинающиеся с `{` без соответствующей закрывающей скобки
3. **Стандартизировать астрономические символы**: выбрать единый формат (с `\text{}` или без)
4. **Исправить артефакты**: `???}`, лишние пробелы, странные символы
5. **Унифицировать `min/max`**: решить между `\min`, `\text{min}`, `min`
6. **Проверить использование запятых**: когда запятая нужна, а когда нет
