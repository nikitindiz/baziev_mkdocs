# Формула (6.3): Знак минус правильный

## Проверка математического преобразования

### Исходные формулы:

-   **(6.1)**: `η = (Q₁ - Q₂)/Q₁ = 1 - Q₂/Q₁` — энергетическое выражение КПД
-   **(6.2)**: `η = (T₁ - T₂)/T₁ = 1 - T₂/T₁` — термическое выражение КПД
-   **(6.3)**: `Q₂/Q₁ = -T₂/T₁` — соотношение из (6.1) и (6.2)
-   **(6.4)**: `Q₁/T₁ + Q₂/T₂ = 0` — приведенные количества теплоты

### Проверка преобразования (6.1) и (6.2) → (6.3):

Приравнивая правые части (6.1) и (6.2):

```
1 - Q₂/Q₁ = 1 - T₂/T₁
-Q₂/Q₁ = -T₂/T₁
Q₂/Q₁ = T₂/T₁
```

**Вопрос:** Откуда минус в (6.3)?

**Ответ:** Q₂ и T₂ имеют противоположные знаки! В цикле Карно:

-   T₁ > T₂ (горячий резервуар и холодный)
-   Q₁ > 0 (подводимая энергия, положительная)
-   Q₂ < 0 (отводимая энергия, отрицательная по соглашению)

Если Q₂ отрицательно, то:

```
Q₂/Q₁ = -|Q₂|/Q₁  (где |Q₂| > 0)
T₂/T₁ = |T₂|/T₁   (где T₂ > 0)
```

Следовательно: `Q₂/Q₁ = -T₂/T₁` ✅

### Проверка преобразования (6.3) → (6.4):

Из (6.3) с минусом: `Q₂/Q₁ = -T₂/T₁`

Умножаем крест-накрест:

```
Q₂ · T₁ = -Q₁ · T₂
Q₂ · T₁ + Q₁ · T₂ = 0
Делим на T₁ · T₂:
Q₂/T₂ + Q₁/T₁ = 0
```

**Результат:** `Q₁/T₁ + Q₂/T₂ = 0` — это точно (6.4)! ✅

### Если бы убрали минус:

Из Q₂/Q₁ = T₂/T₁ (БЕЗ минуса):

```
Q₂ · T₁ = Q₁ · T₂
Q₂ · T₁ - Q₁ · T₂ = 0
Q₂/T₂ - Q₁/T₁ = 0
```

Получили бы: `Q₁/T₁ - Q₂/T₂ = 0` — это НЕ (6.4)! ❌

## Вывод

**Знак минус в формуле (6.3) абсолютно правильный** и необходим для корректного перехода к формуле (6.4).

Физический смысл: Q₂ имеет отрицательный знак, так как это отводимая (отдаваемая) энергия.

✅ Формула (6.3) исправлена: вернули знак минус.
✅ Преобразование (6.3) → (6.4) теперь математически корректно.
