# Методика уточнения определений символов

**Задача**: Систематически проверить и уточнить определения всех символов в базе данных Neo4j, у которых есть общее определение "физическая величина" или "физическая величина или математический символ".

**Цель**: Заменить общие определения на точные, понятные описания каждого символа, которые будут использоваться как подсказки.

## Методика работы

### 1. Поиск символов с общими определениями

```cypher
MATCH (s:Symbol)
WHERE s.definition CONTAINS 'физическая величина'
WITH s ORDER BY s.latex
SKIP N LIMIT 1
RETURN s.id, s.latex, s.definition, s.unit
```

### 2. Поиск формул, использующих символ

```cypher
MATCH (f:Formula)-[:USES_SYMBOL]->(s:Symbol {id: 'symbol_id'})
RETURN f.latex
```

### 3. Поиск контекста через параграфы (ключевой метод)

```cypher
MATCH (f:Formula)-[:USES_SYMBOL]->(s:Symbol {id: 'symbol_id'})
MATCH (p:Paragraph)-[:CONTAINS_FORMULA]->(f)
OPTIONAL MATCH (p)<-[:NEXT*1..3]-(prev:Paragraph)
WHERE size(prev.content) > 100
RETURN substring(p.content, 0, 400) as current_paragraph,
       substring(prev.content, 0, 500) as previous_context
```

### 4. Анализ контекста

- Читаю текст параграфов, где используется символ
- Анализирую формулы с символом
- Проверяю другие символы в той же формуле для понимания контекста
- Изучаю паттерны индексов (элементы, состояния, планеты и т.д.)

### 5. Обновление определения

```cypher
MATCH (s:Symbol {id: 'symbol_id'})
SET s.definition = 'точное описание',
    s.unit = 'единица измерения'
RETURN s.latex, s.definition
```

## Правила работы

### ❌ Запрещено
- НЕ гадать - всегда искать текстовый контекст
- НЕ использовать батчи - работать по одному символу
- НЕ оставлять общие определения

### ✅ Обязательно
- Использовать параграфы через связь `CONTAINS_FORMULA`
- Проверять соседние параграфы через связь `NEXT`
- Указывать единицы измерения где возможно
- Расшифровывать все индексы (что означает каждая буква, цифра, символ)
- Работать по одному символу за раз
- Указывать латексную запись индексов в скобках для ясности

## Полезные запросы

### Проверка прогресса

```cypher
MATCH (s:Symbol)
WHERE s.definition CONTAINS 'физическая величина'
RETURN count(s) as remaining
```

### Поиск похожих символов

```cypher
MATCH (s:Symbol)
WHERE s.latex STARTS WITH 'PREFIX'
RETURN s.latex, s.definition
LIMIT 15
```

### Поиск контекста через другие символы в формуле

```cypher
MATCH (f:Formula)-[:USES_SYMBOL]->(s:Symbol {id: 'symbol_id'})
MATCH (f)-[:USES_SYMBOL]->(other:Symbol)
WHERE other.id <> 'symbol_id'
RETURN DISTINCT other.latex, other.definition
LIMIT 10
```

## Важные замечания

1. **Связь CONTAINS_FORMULA** - основной способ найти параграф, где используется формула
2. **Связь NEXT** - позволяет просматривать соседние параграфы для контекста
3. **Связь BELONGS_TO** - альтернативная связь формул с параграфами (не всегда заполнена)
4. Многие параграфы содержат только ссылки на формулы `{{formula:id}}` - в таких случаях нужно смотреть соседние параграфы
5. Индексы могут быть составными (например, `P_{s⊙i}` = давление на поверхности Солнца для i-го элемента)
