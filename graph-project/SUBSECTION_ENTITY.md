# Сущность Subsection (Подраздел)

## Обзор

**Subsection** — новая сущность в графовой базе данных, представляющая подразделы параграфов книги (заголовки третьего уровня `###`).

## Проблема

В исходной структуре книги параграфы (Section) часто содержат нумерованные подразделы:

```markdown
## § 1. Гиперчастотная механика или механика микромира

### 1. Состояние термодинамики газов.

Текст подраздела...

### 2. Кинетическая энергия осциллятора и его индивидуальное пространство.

Текст подраздела...
```

Ранее эти подразделы не были представлены в графе, что затрудняло:

-   Навигацию по детальной структуре книги
-   Связывание формул и других сущностей с конкретными подразделами
-   Анализ логической структуры аргументации автора

## Решение

Введена новая сущность **Subsection** с полноценной поддержкой в графовой модели.

## Схема сущности

### Атрибуты

| Атрибут  | Тип             | Описание                         | Пример                                             |
| -------- | --------------- | -------------------------------- | -------------------------------------------------- |
| `id`     | STRING (unique) | Уникальный идентификатор         | `"chapter_глава-i_1-гиперчастотная-механика_sub1"` |
| `number` | STRING          | Номер подраздела                 | `"1"`, `"2"`, `"3"`                                |
| `title`  | STRING          | Заголовок подраздела             | `"Состояние термодинамики газов."`                 |
| `order`  | INTEGER         | Порядковый номер в рамках секции | `1`, `2`, `3`                                      |

### Связи (Relationships)

#### Входящие связи

| Связь            | От      | Описание                                                      |
| ---------------- | ------- | ------------------------------------------------------------- |
| `HAS_SUBSECTION` | Section | Секция содержит подразделы. Атрибут `order` указывает позицию |

#### Исходящие связи

| Связь                   | К            | Описание                                  |
| ----------------------- | ------------ | ----------------------------------------- |
| `CONTAINS_PARAGRAPH`    | Paragraph    | Подраздел содержит параграфы текста       |
| `CONTAINS_FORMULA`      | Formula      | Подраздел содержит формулы                |
| `CONTAINS_TABLE`        | Table        | Подраздел содержит таблицы                |
| `CONTAINS_ILLUSTRATION` | Illustration | Подраздел содержит иллюстрации            |
| `CITES`                 | Literature   | Подраздел цитирует литературу             |
| `NEXT`                  | Subsection   | Следующий подраздел в последовательности  |
| `PREVIOUS`              | Subsection   | Предыдущий подраздел в последовательности |

## Структура графа

```
Book
 └─> Chapter
      └─> Section (параграф §)
           └─> Subsection (подраздел 1, 2, 3...)
                ├─> Paragraph (текстовые блоки)
                ├─> Formula (формулы)
                ├─> Table (таблицы)
                ├─> Illustration (иллюстрации)
                └─> Literature (цитирования)
```

## Примеры Cypher запросов

### Получить все подразделы параграфа

```cypher
MATCH (s:Section {id: 'chapter_глава-i_1-гиперчастотная-механика'})-[:HAS_SUBSECTION]->(sub:Subsection)
RETURN sub.number as номер, sub.title as заголовок
ORDER BY sub.order
```

### Найти подраздел по номеру

```cypher
MATCH (s:Section)-[:HAS_SUBSECTION]->(sub:Subsection {number: '1'})
WHERE s.id CONTAINS 'глава-i'
RETURN s.title as параграф, sub.title as подраздел
```

### Получить все формулы в подразделе

```cypher
MATCH (sub:Subsection {id: 'chapter_глава-i_1-гиперчастотная-механика_sub1'})
      -[:CONTAINS_FORMULA]->(f:Formula)
RETURN f.id, f.latex
ORDER BY f.id
```

### Навигация по последовательности подразделов

```cypher
MATCH path = (sub:Subsection {number: '1'})-[:NEXT*]->(next:Subsection)
WHERE sub.id STARTS WITH 'chapter_глава-i_1-гиперчастотная-механика'
RETURN [n IN nodes(path) | n.title] as последовательность_подразделов
```

### Статистика по подразделам

```cypher
MATCH (s:Section)-[:HAS_SUBSECTION]->(sub:Subsection)
RETURN s.title as параграф,
       count(sub) as количество_подразделов
ORDER BY количество_подразделов DESC
LIMIT 10
```

### Найти подразделы с максимальным количеством формул

```cypher
MATCH (sub:Subsection)-[:CONTAINS_FORMULA]->(f:Formula)
WITH sub, count(f) as formula_count
RETURN sub.title as подраздел, formula_count
ORDER BY formula_count DESC
LIMIT 10
```

## Импорт данных

### Скрипт импорта

Для создания узлов Subsection используйте скрипт:

```bash
cd graph-project

# Сначала выполните dry-run для проверки
python import_subsections.py --dry-run

# Если всё корректно, выполните реальный импорт
python import_subsections.py
```

### Параметры запуска

| Параметр        | Описание                                                            |
| --------------- | ------------------------------------------------------------------- |
| `--dry-run`     | Режим пробного запуска без изменений в БД                           |
| `--config PATH` | Путь к файлу конфигурации (по умолчанию ищет в `config/config.yml`) |
| `--help`        | Показать справку                                                    |

**Примеры:**

```bash
# Dry-run с автопоиском конфигурации
python import_subsections.py --dry-run

# Реальный импорт с явным указанием конфига
python import_subsections.py --config /path/to/config.yml

# Справка
python import_subsections.py --help
```

### Алгоритм импорта

1. **Извлечение структуры**: Скрипт читает markdown файлы из `normalized/step-05-extract-and-link-quoted-literature/result/`
2. **Парсинг заголовков**: Находит все заголовки `### N. Название`
3. **Создание узлов**: Создает узлы Subsection с уникальными ID
4. **Связывание с Section**: Создает связи `HAS_SUBSECTION`
5. **Переназначение параграфов**: Связывает существующие Paragraph узлы с соответствующими Subsection
6. **Создание последовательностей**: Создает связи NEXT/PREVIOUS между подразделами

### Важные особенности

⚠️ **БЕЗОПАСНОСТЬ ДАННЫХ**: Скрипт **НЕ изменяет** содержимое существующих узлов (Paragraph, Formula и т.д.), только создает новую структуру и связи.

✓ Скрипт идемпотентен — можно запускать многократно  
✓ Использует MERGE для предотвращения дублирования  
✓ Сохраняет все существующие данные и изменения в базе

## Использование в приложениях

### Генератор сайта

Новая структура позволяет генерировать:

-   Оглавление с детализацией до подразделов
-   Навигацию "предыдущий/следующий" на уровне подразделов
-   Хлебные крошки: Глава > Параграф > Подраздел

### Редактор книги

В `book-editor` можно реализовать:

-   Просмотр и редактирование на уровне подразделов
-   Перемещение формул между подразделами
-   Статистику по подразделам (длина, количество формул)

### Анализ графа

Subsection открывает возможности для:

-   Анализа структуры аргументации
-   Поиска связей между подразделами разных глав
-   Выявления часто цитируемых подразделов

## Миграция существующих данных

Если в базе уже есть данные, скрипт:

1. Создает новые узлы Subsection
2. Связывает их с существующими Section
3. Переназначает существующие Paragraph к Subsection на основе их порядка
4. **НЕ изменяет** содержимое или атрибуты существующих узлов

## Диагностика

### Проверить количество созданных подразделов

```cypher
MATCH (sub:Subsection)
RETURN count(sub) as total_subsections
```

### Проверить связи

```cypher
MATCH (s:Section)-[r:HAS_SUBSECTION]->(sub:Subsection)
RETURN count(r) as total_links
```

### Найти секции без подразделов

```cypher
MATCH (s:Section)
WHERE NOT (s)-[:HAS_SUBSECTION]->()
RETURN s.title, s.id
```

### Проверить последовательности

```cypher
MATCH (sub:Subsection)-[r:NEXT]->()
RETURN count(r) as next_links
```
