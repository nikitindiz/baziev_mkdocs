# Алгоритм поиска описания символов

## Анализ 3 примеров символов из Neo4j

### Пример 1: Символ `V` (объем)

**Текущее состояние в базе:**
- LaTeX: `V`
- Описание: "Извлечено через KaTeX парсер" (авто-генерированное)
- Source: `katex_parser`

**Контекст использования:**
1. В формуле `m_{n⊕} = V_{n⊕} · ρ_n = 2,9866032 · 10²⁴ кг` 
   - Раздел: "38 Закон Вращения И Внутреннее Строение Планет"
   - Используется с индексом `n⊕` (нейтронное ядро Земли)

2. В формуле `ΔV_☉ = (V_☉ - V_{n☉})/T_☉ = 8,0949624 · 10⁹ м³·с⁻¹`
   - Раздел: "26 Структура Конвективной Зоны"
   - Используется с индексом `☉` (Солнце) и `n☉` (нейтронное ядро Солнца)

3. В формуле `V_s`
   - Раздел: "39 Возмущенное Движение Планет И Смещение Центров Их Масс"
   - Контекст: расчеты объемов сегментов и полусфер

**Фактическое значение:** Символ `V` обозначает **объем**

### Пример 2: Символ `\varepsilon` (диэлектрическая проницаемость / энергия)

**Текущее состояние в базе:**
- LaTeX: `\varepsilon`
- Описание: "Извлечено через KaTeX парсер" (авто-генерированное)
- Source: `katex_parser`

**Контекст использования:**
1. В формуле `ε_{tл}` (с индексом "твердое-лёд")
   - Раздел: "18 Фазовые Переходы Воды"
   - Контекст: расчет линейной скорости суперосциллятора льда

2. В формуле `ε_ν = m_э · n_{νi} · a_i · ν_ед / 2 = 𝒫`
   - Раздел: "26 Структура Конвективной Зоны"
   - Связана с массой электрино `m_э`, частотой и энергией

3. В формуле `ε(α, n) = ε_{0i} · n_i / γ_i = ε_{0i} · n_i · n_{si}`
   - Раздел: "11 Уравнение Истинного Состояния Газов"
   - Используется в расчетах состояния газов

**Фактическое значение:** Символ `\varepsilon` обозначает **диэлектрическую проницаемость** или **энергию** (зависит от контекста)

### Пример 3: Символ `m_α` (масса альфа-частицы)

**Текущее состояние в базе:**
- LaTeX: `m_\alpha`
- Описание: "Извлечено через KaTeX парсер" (авто-генерированное)
- Source: `katex_parser`

**Контекст использования:**
1. В формуле `u_α = (i_α - i_э(Au)/2) / m_α = 1,783993 · 10⁷ м·с⁻¹`
   - Раздел: "10 Явление Рассеяния Осциллятора На Осцилляторе У Реальных Газов"
   - Используется в расчете скорости

2. В формуле `i_α = m_α · v_α = 1,2628535 · 10⁻¹⁹ кг·м/с`
   - Раздел: "10 Явление Рассеяния Осциллятора На Осцилляторе У Реальных Газов"
   - Связь массы и скорости (импульс)

3. В формуле `n_2 = v_α/v_{0He} = (m_α · v_α)/(m_{He} · v_{0He})`
   - Раздел: "10 Явление Рассеяния Осциллятора На Осцилляторе У Реальных Газов"
   - Сравнение с массой гелия `m_{He}`

**Фактическое значение:** Символ `m_α` обозначает **массу альфа-частицы**

## Алгоритм поиска описания символа (Промпт)

### Промпт для LLM-анализа символа

```
Ты — эксперт по физике и анализу научных текстов. Твоя задача — определить точное описание символа на основе контекста его использования в научной книге по единой теории физики.

ВХОДНЫЕ ДАННЫЕ:
- Символ (LaTeX): {symbol_latex}
- Список формул, где символ используется: {formulas_list}
- Контекст параграфов, содержащих эти формулы: {paragraphs_context}
- Названия разделов: {section_titles}
- Известные обозначения из справочника: {reference_symbols}

ТВОЯ ЗАДАЧА:
1. Проанализируй все случаи использования символа в формулах
2. Обрати внимание на:
   - Индексы и надстрочные символы (они указывают на конкретный объект)
   - Единицы измерения в формулах (кг, м, с, м³, и т.д.)
   - Физические величины, с которыми символ взаимодействует
   - Названия разделов (они дают тематический контекст)
   - Текст вокруг формул (может содержать прямые упоминания)

3. Определи базовое значение символа:
   - Для букв латинского алфавита: обычно это физические величины (m-масса, V-объем, E-энергия, etc.)
   - Для греческих букв: могут быть коэффициенты, углы, специальные величины
   - Для символов с индексами: базовое значение + уточнение (какого объекта)

4. Сопоставь с известными обозначениями из справочника

5. Сформулируй описание в формате:
   - Краткое описание (1-2 слова): например, "масса", "объем", "скорость"
   - Полное описание (если нужно): например, "масса альфа-частицы", "объем нейтронного ядра"
   - Единицы измерения (если определимы): "кг", "м³", "м/с"
   - Область применения (опционально): "планетная физика", "квантовая механика"

ФОРМАТ ОТВЕТА:
{
  "symbol": "{symbol_latex}",
  "short_description": "краткое описание",
  "full_description": "полное описание",
  "units": "единицы измерения (если применимо)",
  "domain": "область применения",
  "confidence": "высокая/средняя/низкая",
  "reasoning": "обоснование вывода на основе контекста"
}

ПРИМЕРЫ РАССУЖДЕНИЙ:
1. Символ "V" в формулах всегда связан с ρ (плотность) через умножение → это объем (V = m/ρ)
2. Символ "m_α" используется в формулах импульса (m·v) и имеет размерность кг → масса альфа-частицы
3. Символ "ε" встречается в уравнениях состояния газов и имеет индексы материалов → диэлектрическая проницаемость

ВАЖНО:
- Если контекста недостаточно, укажи confidence: "низкая"
- Если символ используется по-разному в разных разделах, укажи это в reasoning
- Базируйся только на фактах из контекста, не додумывай
```

## Алгоритм для автоматизации (Python pseudo-code)

```python
def find_symbol_description(symbol_latex: str) -> dict:
    """
    Алгоритм поиска описания символа в базе Neo4j
    """
    
    # Шаг 1: Собрать все формулы с этим символом
    formulas = query_neo4j("""
        MATCH (s:Symbol {latex: $symbol})<-[:USES_SYMBOL]-(f:Formula)
        RETURN f.latex, f.source
        LIMIT 20
    """, symbol=symbol_latex)
    
    # Шаг 2: Получить контекст параграфов
    contexts = query_neo4j("""
        MATCH (s:Symbol {latex: $symbol})<-[:USES_SYMBOL]-(f:Formula)
        MATCH (p:Paragraph)-[:CONTAINS_FORMULA]->(f)
        MATCH (sec:Section)-[:HAS_PARAGRAPH]->(p)
        RETURN p.content, sec.title, sec.number
        LIMIT 10
    """, symbol=symbol_latex)
    
    # Шаг 3: Проверить справочник условных обозначений
    reference_match = search_in_reference_file(symbol_latex)
    
    # Шаг 4: Собрать статистику использования
    stats = {
        'total_formulas': len(formulas),
        'sections': list(set(c['sec.title'] for c in contexts)),
        'indices_used': extract_indices(formulas),
        'co_occurring_symbols': find_co_occurring_symbols(formulas)
    }
    
    # Шаг 5: Подготовить промпт для LLM
    prompt = prepare_llm_prompt(
        symbol=symbol_latex,
        formulas=formulas,
        contexts=contexts,
        reference=reference_match,
        stats=stats
    )
    
    # Шаг 6: Получить описание от LLM
    description = call_llm(prompt)
    
    # Шаг 7: Валидировать и сохранить
    if description['confidence'] in ['высокая', 'средняя']:
        update_symbol_description(symbol_latex, description)
    
    return description
```

## Эвристические правила для базовых символов

Если LLM недоступен, можно использовать эвристики:

### Латинские буквы:
- `m` (с любыми индексами) → "масса"
- `V` (с любыми индексами) → "объем"
- `v`, `u` → "скорость"
- `E` → "энергия"
- `T` → "температура" или "период"
- `R`, `r` → "радиус"
- `d` → "диаметр" или "расстояние"
- `F` → "сила"
- `P`, `p` → "давление" или "импульс"

### Греческие буквы:
- `ρ` (`\rho`) → "плотность"
- `ε` (`\varepsilon`, `\epsilon`) → "диэлектрическая проницаемость" или "энергия"
- `ν` (`\nu`) → "частота"
- `α` (`\alpha`) → "угол" или "коэффициент"
- `β` (`\beta`) → "коэффициент"
- `γ` (`\gamma`) → "коэффициент Лоренца" или "показатель адиабаты"
- `λ` (`\lambda`) → "длина волны"
- `ω` (`\omega`) → "угловая скорость"

### Специальные символы:
- `⊕` → индекс Земли
- `☉` (`\odot`) → индекс Солнца
- `☿` → индекс Меркурия
- `♀` → индекс Венеры
- `♂` → индекс Марса

## Пример запроса для массового обновления

```cypher
// Найти все символы без описания или с авто-описанием
MATCH (s:Symbol)
WHERE s.description = 'Извлечено через KaTeX парсер' 
   OR s.description IS NULL
   OR s.auto_generated = true

// Получить контекст для каждого символа
OPTIONAL MATCH (s)<-[:USES_SYMBOL]-(f:Formula)
OPTIONAL MATCH (p:Paragraph)-[:CONTAINS_FORMULA]->(f)
OPTIONAL MATCH (sec:Section)-[:HAS_PARAGRAPH]->(p)

WITH s, 
     collect(DISTINCT f.latex)[..5] as sample_formulas,
     collect(DISTINCT sec.title)[..3] as sections,
     count(f) as usage_count

// Вернуть для обработки
RETURN s.latex as symbol,
       s.id as symbol_id,
       sample_formulas,
       sections,
       usage_count
ORDER BY usage_count DESC
```

Этот запрос даст приоритетные символы для обработки (наиболее часто используемые).
