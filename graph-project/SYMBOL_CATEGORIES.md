# Категоризация символов для построения связей в графе знаний

## Цель категоризации

Разделение 1909 символов на категории для:
1. Упрощения навигации по графу знаний
2. Выявления связей между символами разных типов
3. Автоматической валидации корректности формул
4. Улучшения поиска и фильтрации символов
5. Выявления паттернов использования в тексте

## Принципы категоризации

### Множественная принадлежность
Символ может принадлежать **нескольким категориям одновременно**:
- **Основная категория** (primary_category) - главное назначение символа
- **Дополнительные категории** (secondary_categories) - альтернативные контексты использования

### Иерархия категорий
Категории организованы в **трёхуровневую иерархию**:
1. **Супер-категория** (super_category) - высший уровень классификации
2. **Категория** (category) - основной уровень
3. **Подкатегория** (subcategory) - детализация

## Структура категорий

### 1. ФИЗИЧЕСКИЕ_ВЕЛИЧИНЫ (Physical Quantities)
**Описание:** Измеряемые и вычисляемые характеристики физических систем

#### 1.1. Механические величины
- **Скалярные:**
  - `m` - масса
  - `E` - энергия  
  - `P` - мощность
  - `W` - работа
  - `T` - кинетическая энергия
  - `U` - потенциальная энергия
  - `ρ` - плотность
  - `V` - объём

- **Векторные:**
  - `F` - сила
  - `p` - импульс
  - `v` - скорость
  - `a` - ускорение
  - `r` - радиус-вектор

- **Вращательные:**
  - `L` - момент импульса
  - `M` - момент силы
  - `I` - момент инерции
  - `ω` - угловая скорость
  - `α` - угловое ускорение

#### 1.2. Термодинамические величины
- `T` - температура
- `P` - давление
- `S` - энтропия
- `C_V` - теплоёмкость при постоянном объёме
- `C_P` - теплоёмкость при постоянном давлении
- `γ` - показатель адиабаты
- `Q` - количество теплоты
- `η` - КПД

#### 1.3. Электромагнитные величины
- `Q` - электрический заряд
- `I` - сила тока
- `U, V` - напряжение, потенциал
- `E` - напряжённость электрического поля
- `B` - магнитная индукция
- `H` - напряжённость магнитного поля
- `Φ` - магнитный поток
- `ε` - ЭДС
- `R` - сопротивление
- `C` - электрическая ёмкость
- `L` - индуктивность

#### 1.4. Волновые и колебательные величины
- `A` - амплитуда
- `f, ν` - частота
- `ω` - угловая частота
- `λ` - длина волны
- `k` - волновое число
- `φ` - фаза
- `T` - период

#### 1.5. Оптические величины
- `n` - показатель преломления
- `I` - интенсивность излучения
- `Φ` - световой поток
- `E` - освещённость

#### 1.6. Квантовые величины
- `E_n` - энергия уровня
- `ψ` - волновая функция
- `L_z` - проекция момента импульса
- `S` - спин
- `n, l, m` - квантовые числа

#### 1.7. Ядерные и атомные величины
- `A` - массовое число
- `Z` - зарядовое число
- `N` - число нейтронов
- `E_связи` - энергия связи
- `λ` - постоянная распада

**Связи в графе:**
- `MEASURED_IN` → ЕДИНИЦЫ_ИЗМЕРЕНИЯ
- `CALCULATED_BY` → ФОРМУЛЫ
- `DEPENDS_ON` → другие ФИЗИЧЕСКИЕ_ВЕЛИЧИНЫ
- `APPLICABLE_TO` → ФИЗИЧЕСКИЕ_СИСТЕМЫ

### 2. ФУНДАМЕНТАЛЬНЫЕ_КОНСТАНТЫ (Fundamental Constants)
**Описание:** Неизменяемые величины с фиксированным значением

#### 2.1. Универсальные константы
- `c` - скорость света в вакууме (2.998×10⁸ м/с)
- `G` - гравитационная постоянная (6.674×10⁻¹¹ м³/(кг·с²))
- `h` - постоянная Планка (6.626×10⁻³⁴ Дж·с)
- `ℏ` - приведённая постоянная Планка (h/2π)
- `k_B` - постоянная Больцмана (1.381×10⁻²³ Дж/К)
- `N_A` - число Авогадро (6.022×10²³ моль⁻¹)

#### 2.2. Электромагнитные константы
- `e` - элементарный заряд (1.602×10⁻¹⁹ Кл)
- `ε₀` - электрическая постоянная
- `μ₀` - магнитная постоянная
- `α` - постоянная тонкой структуры (≈ 1/137)

#### 2.3. Константы теории Базиева
- `℘` - постоянная Резерфорда
- Специфические константы электрино-осцилляторной модели

#### 2.4. Математические константы
- `π` - число пи (3.14159...)
- `e` - основание натурального логарифма (2.71828...)
- `φ` - золотое сечение (1.618...)

**Связи в графе:**
- `HAS_VALUE` → числовое значение
- `HAS_UNIT` → ЕДИНИЦЫ_ИЗМЕРЕНИЯ
- `APPEARS_IN` → ФОРМУЛЫ
- `DEFINES_SCALE` → физическая область применения

### 3. ЕДИНИЦЫ_ИЗМЕРЕНИЯ (Units of Measurement)
**Описание:** Стандартизованные единицы для выражения физических величин

#### 3.1. Базовые единицы СИ
- `м` - метр (длина)
- `кг` - килограмм (масса)
- `с` - секунда (время)
- `А` - ампер (сила тока)
- `К` - кельвин (температура)
- `моль` - моль (количество вещества)
- `кд` - кандела (сила света)

#### 3.2. Производные единицы СИ
- `Дж` - джоуль (энергия) = кг·м²/с²
- `Вт` - ватт (мощность) = Дж/с
- `Н` - ньютон (сила) = кг·м/с²
- `Па` - паскаль (давление) = Н/м²
- `Тл` - тесла (магнитная индукция)
- `В` - вольт (напряжение)
- `Ом` - ом (сопротивление)
- `Гц` - герц (частота) = с⁻¹
- `Кл` - кулон (заряд) = А·с

#### 3.3. Специальные единицы
- `а.е.` - атомная единица массы
- `эВ` - электронвольт (1.602×10⁻¹⁹ Дж)
- `℃` - градус Цельсия
- `рад` - радиан
- `ср` - стерадиан

#### 3.4. Дольные и кратные приставки
- `нано-` (н, 10⁻⁹)
- `микро-` (μ, 10⁻⁶)
- `милли-` (м, 10⁻³)
- `кило-` (к, 10³)
- `мега-` (М, 10⁶)
- `гига-` (Г, 10⁹)

**Связи в графе:**
- `IS_BASE_UNIT` → булево значение
- `DERIVED_FROM` → базовые единицы
- `MEASURES` → ФИЗИЧЕСКИЕ_ВЕЛИЧИНЫ
- `HAS_DIMENSION` → размерность [M, L, T, I, Θ, N, J]

### 4. ХИМИЧЕСКИЕ_ОБОЗНАЧЕНИЯ (Chemical Notations)
**Описание:** Символы элементов, молекул, ионов и соединений

#### 4.1. Химические элементы
- `H` - водород (Z=1)
- `He` - гелий (Z=2)
- `C` - углерод (Z=6)
- `N` - азот (Z=7)
- `O` - кислород (Z=8)
- `Al` - алюминий (Z=13)
- `Si` - кремний (Z=14)
- `Fe` - железо (Z=26)
- `Cu` - медь (Z=29)
- `Au` - золото (Z=79)
- `Pb` - свинец (Z=82)
- `U` - уран (Z=92)

#### 4.2. Простые молекулы
- `H₂` - молекулярный водород
- `O₂` - молекулярный кислород
- `N₂` - молекулярный азот
- `Cl₂` - молекулярный хлор

#### 4.3. Сложные молекулы
- `H₂O` - вода
- `CO₂` - углекислый газ
- `CH₄` - метан
- `NH₃` - аммиак
- `H₂SO₄` - серная кислота

#### 4.4. Ионы
- Катионы: `H⁺`, `Na⁺`, `K⁺`, `Ca²⁺`, `Al³⁺`
- Анионы: `OH⁻`, `Cl⁻`, `SO₄²⁻`, `NO₃⁻`

#### 4.5. Соединения и комплексы
- `NaCl` - хлорид натрия
- `Al₂O₃` - корунд (оксид алюминия)
- `B₄C` - карбид бора

**Связи в графе:**
- `HAS_ATOMIC_NUMBER` → число протонов
- `HAS_MASS_NUMBER` → атомная масса
- `FORMS_MOLECULE` → молекулярные структуры
- `IN_PERIODIC_TABLE` → положение в таблице Менделеева
- `HAS_IONIZATION_STATE` → степень ионизации

### 5. МАТЕМАТИЧЕСКИЕ_ОБЪЕКТЫ (Mathematical Objects)
**Описание:** Символы для математических операций и обозначений

#### 5.1. Арифметические операторы
- `+` - сложение
- `-` - вычитание
- `*`, `×`, `·` - умножение
- `/`, `÷` - деление
- `=` - равенство
- `≠` - неравенство
- `<`, `>`, `≤`, `≥` - сравнение
- `±` - плюс-минус
- `≈` - приблизительно равно
- `∝` - пропорционально

#### 5.2. Алгебраические операции
- `√` - квадратный корень
- `ⁿ√` - корень n-ой степени
- `^`, верхний индекс - возведение в степень
- `log`, `ln` - логарифмы
- `exp` - экспонента
- `|x|` - модуль

#### 5.3. Дифференциальные операторы
- `d` - дифференциал
- `∂` - частная производная
- `∇` - набла (градиент)
- `Δ` - приращение, лапласиан
- `δ` - вариация
- `'` - производная (штрих Ньютона)
- `˙` - производная по времени (точка)

#### 5.4. Интегральные операторы
- `∫` - интеграл
- `∮` - контурный интеграл
- `∬` - двойной интеграл
- `∭` - тройной интеграл

#### 5.5. Суммы и произведения
- `Σ` - сумма
- `∏` - произведение
- `!` - факториал

#### 5.6. Тригонометрические функции
- `sin`, `cos`, `tan` - основные
- `arcsin`, `arccos`, `arctan` - обратные
- `sinh`, `cosh`, `tanh` - гиперболические

#### 5.7. Векторные операции
- `→` - вектор
- `·` - скалярное произведение
- `×` - векторное произведение
- `∇·` - дивергенция
- `∇×` - ротор

**Связи в графе:**
- `OPERATES_ON` → типы операндов
- `RETURNS_TYPE` → тип результата
- `USED_IN` → ФОРМУЛЫ
- `HAS_PROPERTIES` → математические свойства

### 6. ГЕОМЕТРИЧЕСКИЕ_ОБЪЕКТЫ (Geometric Objects)
**Описание:** Обозначения геометрических элементов и фигур

#### 6.1. Точки и вершины
- `A, B, C, D, ...` - точки в пространстве
- `O` - начало координат, центр
- `M, N, P, Q` - произвольные точки

#### 6.2. Линейные размеры
- `r` - радиус (малый)
- `R` - радиус (большой)
- `a, b, c` - стороны фигуры
- `l` - длина
- `d` - диаметр, расстояние
- `h` - высота

#### 6.3. Углы
- `α` - альфа (первый угол)
- `β` - бета (второй угол)
- `γ` - гамма (третий угол)
- `θ` - тета (полярный угол)
- `φ` - фи (азимутальный угол)
- `ψ` - пси (угол поворота)

#### 6.4. Площади и объёмы
- `S` - площадь поверхности
- `A` - площадь (альтернативное)
- `V` - объём

#### 6.5. Геометрические фигуры
- Треугольник, квадрат, круг, сфера
- Эллипс, парабола, гипербола

**Связи в графе:**
- `VERTEX_OF` → геометрическая фигура
- `MEASURES_DISTANCE` → между объектами
- `DEFINES_ANGLE` → между линиями/плоскостями
- `ENCLOSED_BY` → границы

### 7. КООРДИНАТЫ_И_НАПРАВЛЕНИЯ (Coordinates & Directions)
**Описание:** Системы координат и пространственные направления

#### 7.1. Декартовы координаты
- `x` - первая координата (горизонтальная)
- `y` - вторая координата (вертикальная)
- `z` - третья координата (вдоль оси)
- Индексы: `_x`, `_y`, `_z` - компоненты вектора

#### 7.2. Полярные координаты (2D)
- `r` - радиальная координата
- `θ` - полярный угол

#### 7.3. Сферические координаты (3D)
- `r` - радиус
- `θ` - полярный угол (от оси z)
- `φ` - азимутальный угол (в плоскости xy)

#### 7.4. Цилиндрические координаты
- `ρ` - радиальная координата в плоскости
- `φ` - азимутальный угол
- `z` - высота

#### 7.5. Направления
- `индекс r` - радиальное направление
- `индекс t` - тангенциальное
- `индекс n` - нормальное
- `индекс ⊥` - перпендикулярное
- `индекс ∥` - параллельное

**Связи в графе:**
- `COORDINATE_SYSTEM` → тип системы
- `TRANSFORMS_TO` → другая система координат
- `COMPONENT_OF` → векторная величина
- `ORTHOGONAL_TO` → другие направления

#### 8.4. Галактические объекты

#### 8.5. Астрономические параметры
- Орбитальные элементы

### 9. ИНДЕКСЫ_И_МОДИФИКАТОРЫ (Indices & Modifiers)
**Описание:** Уточнения и конкретизация основных символов

#### 9.1. Числовые индексы
- `0` - начальное, нормальное, нулевое состояние
- `1, 2, 3, ...` - порядковые номера, состояния
- `71` - специфический номер элемента/слоя

#### 9.2. Буквенные индексы (латиница)
- `i, j, k` - индексы суммирования
- `n, m` - счётные индексы
- `a, b, c` - буквенные метки
- `e` - электрон
- `n` - нейтрон
- `p` - протон

#### 9.3. Буквенные индексы (кириллица)
- `л` - лёд (твёрдая фаза воды)
- `ж` - жидкость (жидкая фаза)
- `п` - пар (газообразная фаза)
- `т` - твёрдое состояние, триада
- `э` - электрино

#### 9.4. Индексы состояний
- `c` - критическое (critical)
- `max` - максимальное
- `min` - минимальное
- `f` - конечное (final)
- `s` - поверхность (surface)

#### 9.5. Модификаторы (диакритические знаки)
- `'` (штрих) - производная, модифицированное значение
- `''` (двойной штрих) - вторая производная
- `*` (звёздочка) - характерное значение, сопряжённое
- `~` (тильда) - среднее, приближённое значение
- `¯` (черта) - среднее значение
- `^` (крышка) - единичный вектор, оператор
- `˙` (точка) - производная по времени

#### 9.6. Ионизация
- `⁺` - положительный ион
- `⁻` - отрицательный ион
- `²⁺`, `³⁺` - многозарядные катионы
- `²⁻` - многозарядные анионы

#### 9.7. Степени
- `²` - квадрат
- `³` - куб
- `⁻¹` - обратная величина
- `½` - половина

**Связи в графе:**
- `MODIFIES` → основной символ
- `INDICATES_STATE` → физическое состояние
- `SPECIFIES_COMPONENT` → компонента вектора/тензора
- `DENOTES_PARTICLE` → тип частицы

### 10. КОЭФФИЦИЕНТЫ_И_ОТНОШЕНИЯ (Coefficients & Ratios)
**Описание:** Безразмерные и размерные параметры

#### 10.1. Безразмерные коэффициенты
- `K` - общий коэффициент
- `γ` - показатель адиабаты, коэффициент конденсации
- `α` - коэффициент (часто температурный, электродинамический)
- `β` - коэффициент (часто связанный с температурой)
- `ε` - малый параметр, эксцентриситет
- `η` - КПД, коэффициент вязкости
- `μ` - коэффициент трения, магнитная проницаемость
- `κ` - коэффициент теплопроводности

#### 10.2. Численные параметры
- `N` - число частиц, количество
- `n` - концентрация (частиц/м³)
- `Z` - атомный номер, зарядовое число
- `A` - массовое число

#### 10.3. Отношения и пропорции
- Соотношения физических величин
- Относительные величины
- Доли и проценты

**Связи в графе:**
- `IS_DIMENSIONLESS` → булево значение
- `RELATES` → связанные величины
- `CHARACTERIZES` → физическая система/процесс
- `RANGES_FROM_TO` → область значений

### 11. СОСТОЯНИЯ_И_УСЛОВИЯ (States & Conditions)
**Описание:** Характеристики состояния системы или условий эксперимента

#### 11.1. Термодинамические состояния
- Нормальные условия: `T₀ = 273.15 K`, `P₀ = 101325 Па`
- Стандартные условия
- Критическое состояние

#### 11.2. Фазовые состояния
- Твёрдое (индекс `л` для льда, `т` для триады)
- Жидкое (индекс `ж`)
- Газообразное (индекс `п` для пара)
- Плазма

#### 11.3. Квантовые состояния
- Основное состояние
- Возбуждённое состояние
- Энергетические уровни

#### 11.4. Начальные/конечные состояния
- `индекс 0` - начальное
- `индекс f` - конечное (final)
- `индекс i` - промежуточное (intermediate)

#### 11.5. Экстремальные состояния
- `индекс max` - максимум
- `индекс min` - минимум
- `индекс c` - критическое (critical)

**Связи в графе:**
- `DEFINES_STATE_OF` → физическая система
- `AT_TEMPERATURE` → температура
- `AT_PRESSURE` → давление
- `TRANSITION_TO` → другое состояние

### 12. ТЕОРЕТИЧЕСКИЕ_КОНСТРУКТЫ (Theoretical Constructs)
**Описание:** Специфические понятия теории Базиева

#### 12.1. Элементарные частицы теории
- `э` - электрино (фундаментальная частица)
- Модифицированные представления стандартных частиц
- `ν` - нейтрино (в контексте теории)

#### 12.2. Структурные образования
- **Осциллятор** - базовая колеблющаяся структура
- **Суперосциллятор** - комплексная колебательная система
- **Глобула** - шаровое образование молекул
- **Триада** - структура из трёх молекул воды
- **Дитриада** - двойная триада

#### 12.3. Параметры осцилляторов
- Линейная скорость осциллятора `v`
- Скорость блуждания глобулы `u`
- Амплитуда колебаний `A`
- Гиперчастота `f`

#### 12.4. Специфические взаимодействия
- Электродинамическое поле
- Модифицированная гравитация
- Гиперчастотные процессы

**Связи в графе:**
- `DEFINED_IN_THEORY` → теория Базиева
- `REPLACES_CONCEPT` → стандартная физика
- `HAS_PARAMETER` → специфические параметры
- `EXPLAINS_PHENOMENON` → физическое явление

## Связи между категориями в графе

### Основные типы связей (relationships)

#### 1. Связи использования
- `USES` - формула использует символ
- `APPEARS_IN` - символ появляется в формуле/тексте
- `DERIVED_FROM` - выведено из других символов
- `CALCULATED_BY` - вычисляется через формулу

#### 2. Связи классификации
- `BELONGS_TO_CATEGORY` - принадлежит категории
- `IS_SUBCATEGORY_OF` - подкатегория категории
- `ALTERNATIVE_NOTATION` - альтернативное обозначение
- `SYNONYM_OF` - синоним

#### 3. Связи определения
- `MEASURED_IN` - измеряется в единицах
- `HAS_DIMENSION` - имеет размерность
- `HAS_VALUE` - имеет значение (для констант)
- `RANGES_FROM_TO` - область значений

#### 4. Физические связи
- `DEPENDS_ON` - зависит от величины
- `PROPORTIONAL_TO` - пропорциональна
- `INVERSELY_PROPORTIONAL` - обратно пропорциональна
- `ORTHOGONAL_TO` - ортогональна (для векторов)

#### 5. Химические связи
- `IS_ISOTOPE_OF` - изотоп элемента
- `FORMS_COMPOUND` - образует соединение
- `IN_PERIODIC_TABLE` - положение в таблице
- `HAS_ATOMIC_NUMBER` - атомный номер

#### 6. Контекстные связи
- `APPLICABLE_TO` - применимо к системе
- `DESCRIBES_STATE` - описывает состояние
- `CHARACTERISTIC_OF` - характеристика объекта
- `OBSERVED_IN` - наблюдается в

## Применение категорий для построения связей

### 1. Валидация формул
Проверка корректности формул на основе категорий:
- Математические операторы должны связывать совместимые величины
- Единицы измерения должны согласовываться
- Константы используются в правильном контексте

### 2. Поиск связанных символов
- Символы из одной категории часто появляются вместе
- Химические элементы связаны через реакции
- Физические величины через законы и формулы

### 3. Автоматическое дополнение
- При вводе формулы предлагать символы из релевантных категорий
- Подсказки по единицам измерения
- Связанные константы

### 4. Визуализация графа
- Цветовая кодировка узлов по категориям
- Группировка символов
- Фильтрация по категориям

### 5. Анализ текста
- Извлечение физических величин
- Идентификация химических формул
- Распознавание математических выражений

## Схема добавления категорий в Neo4j

### Вариант 1: Категория как свойство узла
```cypher
MATCH (s:Symbol {id: 'symbol_id'})
SET s.primary_category = 'ФИЗИЧЕСКИЕ_ВЕЛИЧИНЫ'
SET s.subcategory = 'Механические скалярные'
SET s.secondary_categories = ['МАТЕМАТИЧЕСКИЕ_ОБЪЕКТЫ']
```

### Вариант 2: Категория как отдельный узел (рекомендуется)
```cypher
// Создание узла категории
CREATE (c:Category {
  id: 'cat_physical_quantities',
  name_ru: 'ФИЗИЧЕСКИЕ_ВЕЛИЧИНЫ',
  name_en: 'PHYSICAL_QUANTITIES',
  level: 1,
  description: 'Измеряемые и вычисляемые характеристики'
})

// Создание подкатегории
CREATE (sc:Subcategory {
  id: 'subcat_mechanical_scalar',
  name_ru: 'Механические скалярные',
  name_en: 'Mechanical Scalar',
  level: 2
})

// Связь категории и подкатегории
CREATE (sc)-[:IS_SUBCATEGORY_OF]->(c)

// Связь символа с категорией
MATCH (s:Symbol {id: 'symbol_E'}), (c:Category {id: 'cat_physical_quantities'})
CREATE (s)-[:BELONGS_TO_CATEGORY {is_primary: true}]->(c)

MATCH (s:Symbol {id: 'symbol_E'}), (sc:Subcategory {id: 'subcat_mechanical_scalar'})
CREATE (s)-[:BELONGS_TO_SUBCATEGORY]->(sc)
```

### Вариант 3: Гибридный подход
Основная категория как свойство + связи для дополнительных:
```cypher
MATCH (s:Symbol {id: 'symbol_alpha'})
SET s.primary_category = 'ГРЕЧЕСКИЙ_АЛФАВИТ'

MATCH (s:Symbol {id: 'symbol_alpha'}), (c1:Category {id: 'cat_coefficients'})
CREATE (s)-[:ALSO_USED_AS]->(c1)

MATCH (s:Symbol {id: 'symbol_alpha'}), (c2:Category {id: 'cat_geometric'})
CREATE (s)-[:ALSO_USED_AS]->(c2)
```

## Метаданные категорий

Для каждой категории сохранять:
- **id** - уникальный идентификатор
- **name_ru** - название на русском
- **name_en** - название на английском
- **level** - уровень иерархии (1-3)
- **description** - описание категории
- **examples** - примеры символов
- **parent_category** - родительская категория
- **color** - цвет для визуализации (#RRGGBB)
- **icon** - иконка для UI
- **count** - количество символов в категории

## Рекомендации по автоматизации

### Автоматическое определение категории
На основе анализа:
1. **LaTeX-кода** - `\alpha` → ГРЕЧЕСКИЙ_АЛФАВИТ
2. **Единиц измерения** - если есть unit → ФИЗИЧЕСКИЕ_ВЕЛИЧИНЫ
3. **Названия** - химические элементы по таблице Менделеева
4. **Индексов** - `_0`, `_i` → ИНДЕКСЫ_МОДИФИКАТОРЫ
5. **Символов** - Unicode астрономических символов → АСТРОНОМИЧЕСКИЕ

### ML-модель для классификации
Обучение модели на размеченных данных:
- Входные признаки: latex, definition, description, unit, context
- Выходные метки: primary_category, subcategory
- Метод: классификация с множественными метками

## Метрики оценки категоризации

### Покрытие
- % символов с назначенной основной категорией
- % символов с подкатегорией
- Средняя глубина категоризации

### Качество
- Согласованность: одинаковые символы в одной категории
- Полнота: все релевантные категории представлены
- Точность: символы в правильных категориях

### Связность
- Среднее количество связей между категориями
- Плотность графа связей
- Количество мультикатегориальных символов
