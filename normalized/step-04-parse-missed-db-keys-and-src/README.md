# Step 04: Parse Missed DB Keys and SRC

## Описание

После выполнения Step 03 (извлечение иллюстраций) в markdown файлах остались `div`-обёртки с метаданными `data-db-key` и `data-src` вокруг ссылок на формулы. Эти обёртки были пропущены на этапе Step 01, так как формулы внутри них уже были извлечены.

Этот шаг решает эту проблему:
1. Копирует файлы из `step-03/result` в `step-04/result`
2. Находит все такие `div`-обёртки в новых файлах
3. Извлекает метаданные из атрибутов
4. Обновляет соответствующие JSON файлы формул
5. Удаляет обёртки, оставляя только чистые ссылки на формулы

## Структура пропущенных обёрток

### Исходный формат (в step-03/result)

```html
<div data-db-key="30" data-src="images/formula_full_2_9.webp">

{{formula:c6fed30764ee}}

</div>
```

### Результат обработки (в step-04/result)

```markdown
{{formula:c6fed30764ee}}
```

При этом JSON файл формулы `formulas/formula_c6fed30764ee.json` будет обновлён:

```json
{
  "id": "c6fed30764ee",
  "type": "display",
  "latex": "E_0 = \\frac{1}{2} E_x + \\frac{1}{2} E_y + \\frac{1}{2} E_z = \\frac{3}{2} k T_0",
  "metadata": {
    "db_key": "30",
    "src": "images/formula_full_2_9.webp",
    "equation_number": null
  },
  "source": {
    "file": "chapter_глава-i-система-новейших-фундаментальных-открытий/1-гиперчастотная-механика-или-механика-микромира.md",
    "position": 6389
  },
  "wrapper_html": null
}
```

## Использование

### Запуск скрипта

```bash
cd normalized/step-04-parse-missed-db-keys-and-src
python parse-missed.py
```

### Что делает скрипт

1. **Копирование**: Создаёт копию всех файлов из `step-03/result` в `step-04/result`
2. **Сканирование**: Обходит все `.md` файлы в `step-04/result/`
3. **Поиск**: Находит `div`-обёртки с паттерном `<div data-db-key="..." data-src="...">{{formula:...}}</div>`
4. **Извлечение**: Парсит `data-db-key`, `data-src` и `formula_id` из каждой обёртки
5. **Обновление**: Обновляет JSON файл формулы в `formulas/formula_{id}.json`
6. **Очистка**: Заменяет обёртку на чистую ссылку `{{formula:id}}` в `step-04/result`
7. **Отчёт**: Выводит подробную статистику и сохраняет её в `processing_stats.json`

## Технические детали

### Регулярное выражение

```python
pattern = r'<div\s+data-db-key="([^"]+)"\s+data-src="([^"]+)">\s*\{\{formula:([a-f0-9]{12})\}\}\s*</div>'
```

**Группы захвата**:
- Группа 1: `data-db-key` значение
- Группа 2: `data-src` значение  
- Группа 3: ID формулы (12 символов hex)

### Порядок обработки

Обёртки обрабатываются **в обратном порядке** (от конца файла к началу), чтобы сохранить корректные позиции при множественных заменах в одном файле.

### Обновление JSON

Скрипт модифицирует только поля `metadata.db_key` и `metadata.src`, оставляя остальные поля без изменений.

## Примечания

### Зачем это нужно?

Во время Step 01 формулы внутри `div`-обёрток были корректно извлечены, но сами обёртки остались. На Step 03, когда извлекались иллюстрации, эти обёртки не были обработаны, так как они не соответствуют паттерну SVG-иллюстраций.

### Безопасность

- Скрипт **создаёт новую директорию** `step-04/result/` с копией Step 03
- Скрипт **изменяет** JSON файлы в `formulas/`
- Оригинальные файлы Step 03 остаются без изменений
- Рекомендуется сделать commit перед запуском

### Идемпотентность

Скрипт **условно идемпотентен**:
- ✓ Повторный запуск найдёт 0 обёрток (они уже удалены)
- ✓ Метаданные в JSON уже будут обновлены
- ⚠️ `step-04/result/` будет перезаписана при каждом запуске

## Возможные проблемы

### Файл формулы не найден

```
⚠️  Файл формулы не найден: formula_abc123def456.json
```

**Причина**: Ссылка на формулу существует, но JSON файл отсутствует в `formulas/`

**Решение**: Проверить Step 01 и пересоздать JSON файлы формул

### Неожиданный формат обёртки

Если паттерн не совпадает, обёртка не будет обработана. Проверьте вручную:

```bash
# Найти все div с data-db-key
grep -n 'data-db-key' step-03-extract-all-illustrations/result/**/*.md
```

### Директория не найдена

```
❌ Директория не найдена: step-03-extract-all-illustrations/result
```

**Решение**: Сначала выполните Step 03 или проверьте текущую директорию
